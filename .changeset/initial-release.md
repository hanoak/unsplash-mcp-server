Initial release: a Model Context Protocol (MCP) server for the Unsplash API with 21 read-only tools across photos, search, users, collections, topics, and stats. Includes built-in Unsplash-guideline compliance (ready-to-use attribution + a download-tracking tool), `content_filter=high` defaults, a robust retrying HTTP client with rate-limit handling, and lenient response validation.
